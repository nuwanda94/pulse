# Pulse

High-throughput event ingestion & real-time aggregation API built with FastAPI.

Portfolio-grade project demonstrating async high-throughput design, rate limiting, observability, and automated incremental delivery.

## Status

This repository is implemented incrementally by an automation that picks the next task from `TASKS.md`, implements it, runs linting + type checking, writes tests, and pushes.

All performance numbers will be generated by automated load tests (no manual claims).

## Quickstart (once core is ready)

```bash
docker compose up --build
```

## Development

```bash
make lint
make typecheck
make test
make benchmark   # generates BENCHMARKS.md
```

## Architecture (target)

- FastAPI + Pydantic v2 + Uvicorn (uvloop)
- Redis (buffer + rate limits + cache)
- PostgreSQL + SQLAlchemy 2.0 async
- Prometheus metrics
- API-key auth + per-key rate limiting
- Batch ingest path for high throughput

See `TASKS.md` for the ordered implementation backlog.
